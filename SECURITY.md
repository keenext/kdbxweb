# Security

Please report vulnerabilities privately through GitHub's **Security → Report a vulnerability** on this repository, not as a public issue. Include the version of `@keenext/kdbxweb` and, if possible, a file or steps that reproduce the problem.

This fork is maintained for [KeeNext](https://github.com/keenext/keenext); a problem in how KeeNext uses it can be reported there the same way. The fork has not been independently audited and is provided without warranty (MIT). [FORK.md](FORK.md) lists its changes and the places worth reviewing first.
